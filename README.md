A modern and fully responsive food restaurant website built using HTML, CSS, and JavaScript. This project is designed to showcase a restaurant’s menu, services, and online presence with an elegant dark-themed UI.

*Features*
Beautiful homepage with hero section
Interactive food menu with categories
Fully responsive design (mobile-friendly)
Modern black/dark theme layout
Contact section with location & form
Smooth animations and hover effects
*Technologies Used*
HTML5
CSS3 (Flexbox & Grid)
JavaScript (Vanilla JS)
Purpose

This project is created to help restaurant businesses build an attractive online presence and improve customer engagement. It can also be used as a demo project to gain client trust in web development services.

*Preview*

A stylish and clean UI focused on user experience, fast loading, and modern design trends.
